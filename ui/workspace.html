Notes

A library of Markdown pages kept in this app's own storage, grouped on shelves. Pages never touch your repositories or shared documents. Every save keeps the earlier text, and a page changed elsewhere is never overwritten.

Pre-PR review

Read the draft as it will appear, tick each check, then save PASS (manual review). The label is your own note tied to this exact text: if the file changes it shows as stale. It is not a gate approval and grants nothing.

    App settings

    Make agentVIEW yours. Preferences are saved on this device.

    Loading preferences…

    Appearance

    Molokai Dark, Cyberdream Light and PaperColor Light/Dark across the workspace. Display scaling and interface scale work together.

    Workspace

    Sessions open by default and use your installed Claude Code and Codex CLIs. The simulated demo workspace is off unless enabled here. Start and resume remain explicit actions.

    Terminal

    Applies to open terminals after saving. Scrollback stays in memory; it is not written to disk.

    Token usage

    Automatic checks run only while the Usage page is visible and the window is active. They read matching local records and do not start a CLI.

    Coordinator quick prompts

    Saved presets paste into the selected native prompt without adding Enter. Review before sending.

    Export and import bundle

    A bundle holds your preferences and your Notes library. It leaves out sessions, terminal content, conversations, usage records, review labels, allow-lists, paths and credentials. Bundles are saved to, and imported from, this app's private exports folder only. To move one to another computer, copy the file from that folder. Import adds pages as new pages and never overwrites or deletes existing ones; preferences are replaced only if you tick the box.

    Webhook notifications

    Sends short messages to webhooks you paste (Discord, Slack or any https address that accepts JSON). Choose per destination: a session quiet for 10 minutes ("may be waiting for you"), a session that stopped with an error, or a session that finished normally. Messages name the agent; the app cannot see approvals, so it never says one is pending. Addresses are saved privately on this computer, never shown again (only the host name) and not part of export bundles. Only https addresses on public host names; up to 5 destinations and 20 messages an hour each.

    NameHostEventsState

    Back up exports with rclone

    Copies the files in this app's exports folder to a remote you already set up in rclone, into agentview-backup/exports. It only adds files: nothing is deleted or overwritten. The app never reads or shows your rclone settings, only the remote names.

    About & diagnostics

    CLI versions come from registered sessions. Login, models and approvals use native provider controls.

    The diagnostic report excludes prompts, conversations, session IDs, storage paths, account details and credentials.
