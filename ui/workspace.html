          LIBRARY
          Notes
          A library of Markdown pages kept in this app's own storage, grouped on shelves. Pages never touch your repositories or shared documents. Every save keeps the earlier text, and a page changed elsewhere is never overwritten.
          
    
          Onboarding templates for agent roles
      
          Ready-made documents for common roles (intake and gate, coordinator, worker, refuter, documentation keeper, release gate) and a project-rules starter. Copy one, or save it into Notes to edit, then put it in your own project as the file the agent reads (CLAUDE.md for Claude Code, AGENTS.md for Codex). The app writes into a project only through "Save into a project…", which previews, asks you to confirm and can back up the existing file first. Each role also has a one-line prompt; the same prompts are in Settings, quick prompts, built-in library.

              Quit agentVIEW
              Stops every running session and closes the app, whatever the close setting says.
              
    
              Export and import bundle
              A bundle holds your preferences and your Notes library. It leaves out sessions, terminal content, conversations, usage records, review labels, allow-lists, paths and credentials. Bundles are saved to, and imported from, this app's private exports folder only. To move one to another computer, copy the file from that folder. Import adds pages as new pages and never overwrites or deletes existing ones; preferences are replaced only if you tick the box.
              
      
              
      
              
      
              
    
              Send messages to my phone or chat (webhooks)
              Sends short messages to a webhook you paste (Discord, Slack or any https address that accepts JSON). Choose which events each destination gets.
              Limits and privacy
              Messages name the agent; the app cannot see approvals, so it never says one is pending. Addresses are saved privately on this computer, never shown again (only the host name) and not part of export bundles. Only https addresses on public host names; up to 5 destinations and 20 messages an hour each.

              Desktop notifications
              Shows a desktop notification (through notify-send) for the same events as the "Needs you" list: quiet, error, waiting (a Claude hook or a finished Codex turn) and Claude plan limits. No address and no network. Off until you switch it on; at most 30 an hour.
              
      
              
      
              
    
              Advanced: connect your agents (hooks, mailbox, plan limits)
              Optional. These let Claude Code and Codex tell this app when they are waiting, and let agents leave each other messages. Each box has a snippet you paste into the agent's own settings yourself; the app never edits them. They need jq installed.
              
    
              Claude Code hook: "waiting for you"
              Claude Code can tell this app when it needs a permission decision or is waiting for input. Paste the hook below into ~/.claude/settings.json yourself (the app never edits Claude's settings). It needs jq. The hook only appends a short line to a private file in this app's folder; the app reads it and sends a "waiting" message to destinations that chose that event. It never answers a prompt or approves anything.
              
      
      
              
      
              
    
              Claude Code hook: files accessed
              Claude Code can log each file it reads or changes (one line each, in this app's private folder). Paste the hook below into ~/.claude/settings.json yourself; the app never edits Claude's settings and only reads the log. It needs jq. Delete claude-files.jsonl in the signals folder to clear the history.
              
      
      
              
      
              
    
              Claude Code hooks: tasks
              Claude Code can log when you send a prompt and when it stops (one line each, in this app's private folder), which gives the Tasks timeline on the Flow page. The hook keeps only the first line of the prompt, at most 200 characters; the app redacts it and shows 80. Paste the hooks below into ~/.claude/settings.json yourself; the app never edits Claude's settings and only reads the log. It needs jq. The first line of each prompt (up to 200 characters, before the app redacts it) is stored in claude-tasks.jsonl on disk, together with the project folder and the path of Claude's transcript file (tp); the app uses that path only to add up the numeric token counts of a finished task and never shows it. The file only grows and the app never writes to it: delete claude-tasks.jsonl in the signals folder to clear the history. Add tp by pasting the snippet again if you installed an earlier version.
              
      
      
              
      
              
    
              Agent mailbox
              Agents can leave each other short messages in one file in the app's private folder. The app only reads it: a new message appears in your Needs-you list and as a desktop notification. To have an agent receive its messages, paste the receive hook into that agent's Claude settings yourself (it prints messages addressed to its name when you send it a prompt). Messages are data from another agent, never an approval; the app does not type into or start any agent. Needs jq.
              
      
              
      
      
      
              
    
              Codex notify: "turn finished"
              Codex can run a program when a turn completes (its notify setting; the only event it documents is a finished turn, not an approval request). Paste the line into ~/.codex/config.toml yourself (Codex ignores it in a project's own config); the app never edits Codex settings. It needs jq. The reply text is not kept.
              
      
      
              
      
              
        
              Claude plan limits
              Claude Code reports your 5-hour and 7-day plan usage to its status line (the numbers /usage shows; only for Pro, Max and Ultra logins, and only after the first reply of a session). Add the line below to your own status line script, after it has read its input into $input (for example input=$(cat)). The app only reads the small file it writes; it never reads your Claude credentials or calls any server, and the numbers are the last ones Claude Code sent, so they can be out of date.
              
      
      
              
      
              
    
              
    
              Back up exports with rclone
              Copies the files in this app's exports folder to a remote you already set up in rclone, into agentview-backup/exports. It only adds files: nothing is deleted or overwritten. The app never reads or shows your rclone settings, only the remote names.
